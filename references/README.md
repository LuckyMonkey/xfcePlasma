# Visual geometry references

`houndstooth-reference.svg` is Kevin L. Durette's 2014 tessellating
houndstooth SVG from Wikimedia Commons, used as the geometric reference for
`ricky.fs`.

- Source: https://commons.wikimedia.org/wiki/File:Houndstooth_SVG.svg
- License: Creative Commons Attribution 4.0 International
- Changes: the 400 × 400 polygon coordinates were normalized to a 4 × 4
  procedural GLSL tile; animation affects color and lighting, not the tooth
  silhouette.
